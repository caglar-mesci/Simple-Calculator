# Simple Calculator (Tkinter)

This is a simple calculator application built using **Python** and **tkinter**.  
It supports basic arithmetic operations such as:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

The project is designed as a beginner-friendly GUI application and is suitable
for learning basic GUI development in Python.

---

## Features

- Clean and simple user interface
- Button-based input system
- Safe evaluation of expressions
- Error handling for invalid inputs
- Lightweight and easy to run

---

## Technologies Used

- Python 3
- Tkinter (standard Python GUI library)
